# Security Policy

## Supported Versions

We provide security updates for the following versions of Creativa:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Creativa team takes security issues seriously. If you discover a security vulnerability in Creativa, please report it privately:

1. **Do not create a public GitHub Issue**.
2. Email your vulnerability report to [security@creativa.design] or contact maintainers directly.
3. Include the following details:
   - Type of vulnerability (e.g. XSS, Client-Side Data Leakage, Dependency Vulnerability).
   - Step-by-step instructions or PoC (Proof of Concept) to reproduce.
   - Any suggested mitigations or patches.

### Response Time

- You will receive an acknowledgment of your report within **48 hours**.
- We will coordinate a fix and release a patched version as soon as possible.
- Security researchers who follow responsible disclosure practices will be credited in our release notes.
